# 📊 Infografías — Javier Aguilar

Colección de infografías sobre desarrollo de software, frameworks, arquitectura y carrera tech.  
Diseñadas para la comunidad. Libres para descargar, editar y usar.

---

## ¿Por qué existe este repo?

Creo que el conocimiento técnico debería ser visual, claro y accesible.  
Cada infografía nace de un debate real, una decisión de arquitectura o una lección aprendida en proyectos reales — no de teoría copiada de la documentación.

La intención es simple: que cualquier desarrollador pueda llevarse algo útil en menos de 30 segundos de lectura.

---

## 🚀 ¿Cómo usar las infografías?

Cada infografía está disponible en dos formatos:

- **`.html`** — versión interactiva con botón de descarga PNG integrado
- **`.png`** — imagen lista para compartir en LinkedIn, Twitter o donde quieras

### Descargar
1. Entra al archivo `.html` de la infografía que te interese
2. Haz clic en el botón **"Descargar PNG"**
3. Listo — imagen en alta resolución en tu carpeta de descargas

### Editar
1. Clona el repo: `git clone https://github.com/JavierAguilarDeveloper/infografias`
2. Abre el `.html` en tu editor favorito
3. Modifica el contenido, colores o estructura a tu gusto
4. El diseño está construido en HTML/CSS puro — no necesitas ningún framework
