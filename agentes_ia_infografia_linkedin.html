// componentes internos

🧠
LLM Core
El "cerebro". GPT-4, Claude, Gemini. Decide qué hacer con el contexto disponible.
🔧
Herramientas
APIs, búsqueda web, ejecución de código, base de datos. Lo que el LLM no sabe, lo busca.
💾
Memoria
Short-term (contexto), Long-term (vector DB). Recuerda entre turnos y sesiones.
🎯
Planner
Descompone objetivos complejos en subtareas secuenciales o paralelas.
🔐
Guardrails
Límites de seguridad. Evalúa si la acción es permitida antes de ejecutar.
📊
Feedback
Observa el resultado de cada acción. Si falló, ajusta la estrategia.

// agente vs chatbot

Chatbot clásico
  • Responde a una sola entrada
  • Sin memoria persistente
  • No ejecuta acciones externas
  • Flujo controlado por el usuario
Agente de IA
  • Loop autónomo multi-paso
  • Memoria entre sesiones
  • Llama APIs, escribe archivos
  • Se autodirige hasta lograr el objetivo
