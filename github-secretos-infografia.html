Abre cualquier repo como entorno completo desde el navegador. Sin instalar absolutamente nada.

Dependabot: seguridad automática
Escanea dependencias y abre PRs de fix automático cuando detecta vulnerabilidades.
seguridad

Releases: changelog profesional
Versiona tu software, adjunta binarios y genera notas de release automáticas.
versioning
